## 0. 1장 카드뉴스의 원칙 (가장 중요)

표지·본문·마무리가 분리된 다중 페이지와 달리, 1장 카드뉴스는 **한 화면 안에서 기·승·전·결을 모두 끝낸다.** 따라서 다음을 지킨다.

| 원칙 | 적용 |
|---|---|
| **단일 메시지** | 한 장에 핵심 메시지 1개. 두 개 이상의 주제를 욱여넣지 않는다 |
| **3초 가독** | 모바일 썸네일(원본의 1/4)에서 헤드라인이 즉시 읽혀야 한다 |
| **자기완결성** | 제목·핵심 정보·기관 시그니처가 한 장에 모두 포함 |
| **상속된 톤** | 본문 가이드의 타이포·컬러·3D 매트 일러스트 룩을 그대로 사용 |

**포스터형** — 모집공고·행사안내·정책공지 등 **행동 유도**가 필요한 보도자료에 사용한다.

## 1. 캔버스 / 비율

| 항목 | 값 |
|---|---|
| 종횡비 | **4 : 5 (세로형)** |
| 권장 해상도 | 1080 × 1350 px |
| 앱 생성 해상도 | 800 × 1000 px (동일 비율, GPT Image용) |
| 안전 여백 | 좌우 56 px, 상하 56 px |
| 배경 | 신뢰 블루 무드색 (아래 §5). 정보 가독성 우선, 순백에 가깝게 |

1장은 본문 페이지보다 **상하 여백을 약간 더 주어** 한 화면의 완성도·균형감을 확보한다.

## 2. 포스터형 (Poster)

### 추천 용도
모집 공고 · 신청 안내 · 간단한 정책 공지 · 행사 안내 · 참여 독려 · 공모전 모집

### 대표 사례
청년자문단 모집 · 국민자문단 모집 · 요소수 매점매석 금지 · 폐자원 수입관세 안내 · 설명회 개최 안내

### 페이지 구조
```
┌─────────────────────────────────────┐
│ ① 시리즈 칩 + 기관 로고(우)          │  ← 상단 8%
├─────────────────────────────────────┤
│ ② 강한 헤드라인 (1~2줄, 정책명 강조) │  ← 18~24%
├─────────────────────────────────────┤
│ ③ 대표 3D 일러스트 / 상징 오브젝트   │  ← 30~38%
├─────────────────────────────────────┤
│ ④ 핵심 안내 (대상·기간·방법)         │  ← 20~26%
│    [컬러 칩 헤더] + 불릿 2~4개        │
├─────────────────────────────────────┤
│ ⑤ CTA 밴드 (신청 방법·문의처)        │  ← 10~12%
├─────────────────────────────────────┤
│ ⑥ 발행 기관 시그니처                 │  ← 4%
└─────────────────────────────────────┘
```

### 디자인 특징
- 강한 헤드라인 중심, 공공기관 포스터 톤
- 신청기간·대상·문의처를 **명확한 위계**로 분리
- 하단에 **CTA(Call To Action)** 밴드 1개 — 색 대비로 시선 유도
- 핵심 정보만 간결하게, 장식 최소화

### 썸네일 컨셉
"정부 공고문 스타일의 깔끔하고 신뢰감 있는 포스터"

## 3. 타이포그래피 (1080 × 1350 기준)

표지·본문과 동일 서체군(Pretendard / 에스코어드림 / 나눔스퀘어 Neo).

| 역할 | 크기 | 굵기 | 컬러 | 비고 |
|---|---|---|---|---|
| 시리즈 칩 텍스트 | 22–26 px | Bold | #1A2238 / 칩색 따라 흰색 | 칩 배경: 옅은 그레이 또는 무드색 |
| **헤드라인** | **64–84 px** | **ExtraBold (800)** | #1A2238 | 1~2줄, 정책명 강조 |
| 안내 불릿(■) | 26–32 px | Regular/Medium | #1A2238 | 행간 1.55, 대상·기간·방법 |
| CTA 텍스트 | 30–36 px | Bold | 흰색 | 컬러 밴드 위 |
| 보조 메타 `(’26.~, 1억원)` | 22–26 px | Regular | #6A6F7E | 괄호 메타 정보 |

### 키워드 강조 (3가지 중 택1, **한 장 내 1종 통일**)
1. **하단 컬러 블록**: 글자 뒤 50% 높이 액센트 배경
2. **굵기 + 액센트 컬러**: `**모두의 '로컬창업'**`
3. **밑줄 액센트**: 글자 아래 4–6 px 라인

본문 가이드의 무드 A/B/C를 포스터형에 매핑한다. 섹션 톤(앱 설정)이 우선한다.

| 역할 | HEX |
|---|---|
| 페이지 배경 | `#EAF3FB` ~ `#F7FAFD` |
| 메인 텍스트 | `#1B2A4E` |
| 시리즈 칩 배경 | `#CDE7F5` |
| 안내 카드 헤더 칩 | `#4D99D8` |
| CTA 밴드 | `#236EA8` (흰 텍스트) |
| 강조 부호 `!` | `#E14B4B` |

## 5. 일러스트레이션 가이드

표지·본문과 같은 **3D 매트 렌더 룩** 유지. 사진/플랫 아이콘 혼용 금지.

- 대표 캐릭터 + 1~2개 상징 오브젝트(서류·달력·확성기 등)
- 캔버스 폭의 **40~55%**, 중앙 또는 헤드라인 아래 배치
- 배경 없이 누끼, 그림자만 살짝

### 화살표·흐름 표현
```
■ 메인 항목 (큰 사각형, 굵게)        ■ 컬러: #1A2238
➡ 하위 보조 항목 (작은 화살표, 인덴트)  ➡ 컬러: 액센트, 들여쓰기 24~32 px
```

## 6. 보조 그래픽 요소

### 시리즈 칩 (상단 좌측)
- 라운드 12 px, 좌우 패딩 20 px, 높이 44~50 px
- 우측에 기관 로고 인라인 배치 가능

### 안내 카드 컨테이너
- 라운드 24~32 px, 그림자 `0 4 16 rgba(0,0,0,0.04)`
- 내부 패딩 32~40 px

### CTA 밴드
- 페이지 하단 가로 전폭 또는 라운드 사각형
- 액센트 풀컬러 + 흰 텍스트, "지금 신청하기 →" 식

---

## 7. 체크리스트 (1장 출고 전)

- [ ] 한 장에 핵심 메시지가 **1개**로 좁혀졌는가
- [ ] 헤드라인이 모바일 썸네일에서 즉시 읽히는가
- [ ] 키워드 강조 방식이 한 장 내 **1종으로 통일**되었는가
- [ ] 대상·기간·방법·문의처가 위계로 분리되고 CTA가 있는가
- [ ] 메타 정보(`(’26.~, 1억원)`)가 본문보다 흐린 그레이인가
- [ ] 3D 일러스트 룩이 표지·본문 시스템과 동일한가
- [ ] 하단 기관 시그니처(로고) 위치·크기·컬러가 일관된가
- [ ] 일본·북한·식민지 잔재, 정치 이념·갈등, 혐오 표현이 없는가

```html
<article class="cn1 cn1--poster">
  <header class="cn1-top">
    <span class="series-chip">청년 정책 안내</span>
    <span class="cn1-logo"><!-- 기관 로고 --></span>
  </header>
  <h1 class="cn1-headline">2026 <em>청년자문단</em> 모집</h1>
  <div class="cn1-hero"><!-- 3D 캐릭터 + 상징 오브젝트 --></div>
  <section class="cn1-card">
    <span class="card-chip">모집 안내</span>
    <ul class="cn1-bullets">
      <li><b>대상</b> 만 19~34세 청년 누구나</li>
      <li><b>기간</b> ’26.3.1 ~ 3.31 <span class="meta">(온라인 접수)</span></li>

  <footer class="cn1-sig"><!-- 기관 엠블럼 --></footer>
</article>
```
