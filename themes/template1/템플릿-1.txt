## 0. 이 템플릿의 정체성 (가장 중요)

이 1장 템플릿은 **2장 이상 템플릿(`themes/template2`의 표지·본문)과 디자인이 절대로 겹치지 않는다.**
2장 템플릿이 "밝은 컬러 배경 + 3D 클레이 캐릭터 + 키워드 배지 + 캠페인 슬로건" 중심이라면,
**이 1장 템플릿은 "흰 배경 + 큰 통계 수치 + 데이터 차트 + 비교 컬럼 + 실물형 3D 오브젝트"** 중심의
**통계·데이터 발표용 인포그래픽**이다.

| 구분 | **이 1장 인포그래픽형 (사용)** | 2장 표지·본문 (금지·회피) |
|---|---|---|
| 배경 | **순백 `#FFFFFF` / 아주 옅은 회색** | 하늘색 그라데이션·웜 화이트·구름·도시 실루엣 |
| 주인공 | **큰 숫자(%·억원)·라인/바 차트** | 3D 클레이 사람 캐릭터·모모·페페 |
| 정보 단위 | **2열 비교 컬럼 + 가는 선 아이콘 + 세로 분리선** | 키워드 배지(알약)·시리즈 칩·CTA 밴드 |
| 일러스트 | **실물형 3D 오브젝트(장바구니·생선·동전 등)를 모서리에 소품으로** | 캐릭터 군상·말풍선·원형 장식 배경 |
| 하단 | **회색 선언형 요약 문단(키워드 굵게)** | 기관 캐릭터 + 슬로건 보드 |

> **금지:** 시리즈 칩, 키워드 배지 줄, CTA 밴드("지금 신청하기 →"), 3D 사람 캐릭터, 하늘색 그라데이션 배경, 구름·도시 실루엣. 이것들은 2장 템플릿 전용이다.

## 2. 페이지 구조 (위→아래 6블록)

```
┌──────────────────────────────────────────┐
│ ① 기관 로고+명(좌상단)        [3D 소품(우상)]│  ← 상단 8%
├──────────────────────────────────────────┤
│ ② 헤드라인: 라벨 + 거대 수치 + 단위        │  ← 18~24%
│    예) "2월 소비자물가  2.0% 상승"          │
│    회색 보조설명 1~2줄                      │
├──────────────────────────────────────────┤
│ ③ 2열 비교 컬럼 (가운데 세로 분리선)        │  ← 22~28%
│   [선아이콘] 지표A      │  [선아이콘] 지표B  │
│    설명 + 큰 수치       │   설명 + 큰 수치   │
│    (괄호 메타)          │   (괄호 메타)      │
├──────────────────────────────────────────┤
│ ④ 데이터 차트 (라인/바, 라운드 카드)        │  ← 26~32%
│    범례·끝점 수치 라벨·축 캡션  [3D 소품]    │
├──────────────────────────────────────────┤
│ ⑤ 회색 선언형 요약 문단 (키워드 굵게)       │  ← 10~14%
└──────────────────────────────────────────┘
```

핵심: **한 장 안에서 "무슨 수치가 / 얼마나 / 어떤 추세로 / 정부는 어떻게"** 가 위에서 아래로 한 번에 읽힌다.

## 3. 블록별 가이드

### ① 상단 — 로고 + 소품
- **좌상단**에 재정경제부 엠블럼 + "재정경제부" 텍스트를 인라인으로(높이 40~52 px).
- **우상단 모서리**에 주제를 상징하는 **실물형 3D 오브젝트** 1점(누끼, 그림자만). 예: 식료품 가득한 장바구니, 동전 더미, 주택 모형. 사람 캐릭터 금지.

### ② 헤드라인 — 거대 수치 중심
- 작은 라벨(예: `2월 소비자물가`)을 네이비로 먼저, 그 아래/옆에 **가장 큰 핵심 수치**를 배치.
- 핵심 수치(예: `2.0%`)는 **블루 `#2E6FB7`**, 뒤따르는 동사/방향어(`상승`·`하락`)는 **네이비 `#1A2A4A`**.
- 그 아래 **회색 보조 설명 1~2줄**(예: "식료품과 에너지를 제외한 **근원물가는 2.3% 상승**"). 강조어만 진한 색.

### ③ 2열 비교 컬럼
- 화면을 좌우 2칸으로 나누고 **가운데 얇은 세로 분리선**(`#D7DCE3`, 1~2 px).
- 각 칸 상단에 **가는 선(라인) 픽토그램** 1개(장바구니·가격표 등) — **단색, 채움 없는 외곽선 스타일**. 3D·컬러 아이콘 금지.
- 칸 구성: `지표명(Bold)` → `설명 한 줄` → `큰 수치(블루/네이비, ExtraBold)` → `(괄호 메타 회색)`.

### ④ 데이터 차트
- **라인 차트** 또는 **막대 차트**를 옅은 회색/흰 라운드 카드 위에 배치.
- 선 2종: 주지표 = **네이비 실선 `#1B2A4E`**, 보조지표 = **틸/그린 점선 `#2FA39A`**.
- 시작·끝 데이터 점에 **수치 라벨**을 직접 표기(예: 5.0 / 4.0 → 2.3 / 2.0).
- 우상단 **범례**, 우하단 단위 캡션 `(%,전년동월비)`, 하단 중앙에 차트 제목 칩(`소비자물가·근원물가`).
- 차트 모서리에 작은 3D 소품(예: 생선) 1점 허용 — 과하지 않게.

### ⑤ 하단 요약 문단
- **중앙 정렬 회색 문장**(`#5A6270`), 2~3줄, 행간 1.6.
- "정부는 ~ 할 계획입니다" 식 **선언·약속 톤**. 핵심 키워드만 **진한 네이비 Bold**.
- 예: "정부는 국제유가 변동성이 확대된 만큼 **석유류 가격**과 **수급 상황**을 면밀히 모니터링하며 **체감물가 안정**을 위해 **신속히 대응**할 계획입니다."

## 5. 컬러 시스템 — 데이터 인포그래픽 (기본)

흰 배경 위에서 **블루 + 네이비 + 틸그린**을 데이터 강조에만 절제해서 쓴다. 섹션 톤(앱 설정)이 있으면 그 색을 핵심 수치·차트 주선에 우선 적용한다.

## 6. 일러스트·아이콘 가이드

두 종류만 쓴다. **사람 3D 캐릭터·플랫 컬러 아이콘은 쓰지 않는다.**

1. **실물형 3D 오브젝트 (모서리 소품)** — 주제를 상징하는 사물 1~2점. 사실적 매트 3D 렌더, 배경 없이 누끼, 부드러운 그림자. 예: 식료품 장바구니, 동전·지폐, 주택 모형, 자동차, 생선·농산물.
2. **데이터 픽토그램 (비교 컬럼)** — **가는 단색 외곽선** 아이콘. 채움·그라데이션 없이 1.5~2 px 라인. 예: 장바구니, 가격표, 그래프, 화살표.

> 이미지 안에 가짜 로고·임의 영문 텍스트를 만들지 말 것. 한글 수치·라벨은 정책 원문과 일치시킨다.

## 7. 체크리스트 (1장 출고 전)

- [ ] 배경이 **흰색**인가 (하늘색 그라데이션·구름·캐릭터가 없는가)
- [ ] 가장 큰 요소가 **핵심 통계 수치**인가
- [ ] 2열 비교 컬럼이 **세로 분리선 + 가는 선 아이콘**으로 구성됐는가
- [ ] 차트의 시작·끝 점에 **수치 라벨**과 **범례·단위 캡션**이 있는가
- [ ] 하단에 **회색 선언형 요약 문단**(키워드 굵게)이 있는가
- [ ] 3D 소품이 **사물형**인가 (사람 캐릭터·모모/페페가 아닌가)
- [ ] 좌상단 **기관 로고+명**, 가짜 로고/임의 텍스트 없음
- [ ] 2장 표지·본문 디자인 요소(시리즈 칩·키워드 배지·CTA 밴드)와 겹치지 않는가
- [ ] 일본·북한·식민지 잔재, 정치 이념·갈등, 혐오 표현이 없는가
