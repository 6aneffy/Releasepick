## 0. 1장 카드뉴스의 원칙 (가장 중요)

표지·본문·마무리가 분리된 다중 페이지와 달리, 1장 카드뉴스는 **한 화면 안에서 기·승·전·결을 모두 끝낸다.** 따라서 다음을 지킨다.

| 원칙 | 적용 |
|---|---|
| **단일 메시지** | 한 장에 핵심 메시지 1개. 두 개 이상의 주제를 욱여넣지 않는다 |
| **3초 가독** | 모바일 썸네일(원본의 1/4)에서 헤드라인이 즉시 읽혀야 한다 |
| **자기완결성** | 제목·핵심 정보·기관 시그니처가 한 장에 모두 포함 |
| **상속된 톤** | 본문 가이드의 타이포·컬러·3D 매트 일러스트 룩을 그대로 사용 |

1장 카드뉴스는 보도자료 성격에 따라 아래 **3가지 유형 중 하나**를 고른다.

- **① 포스터형** — 모집공고·행사안내·정책공지 (행동 유도)
- **② 1장 요약형** — 경제지표·통계·정책성과 (데이터 전달)
- **③ 텍스트 강조형** — 신규정책·캠페인·정책홍보 (메시지 각인)

> 자동 추천 규칙: "모집·신청·접수·공고" → ① / "GDP·물가·신용등급·수출입·예산·%" → ② / "새로운 정책·정책 발표·민생안정·경제활력·혁신" → ③

## 1. 캔버스 / 비율 (3유형 공통)

| 항목 | 값 |
|---|---|
| 종횡비 | **4 : 5 (세로형)** |
| 권장 해상도 | 1080 × 1350 px |
| 앱 생성 해상도 | 800 × 1000 px (동일 비율, GPT Image용) |
| 안전 여백 | 좌우 56 px, 상하 56 px |
| 배경 | 유형별 무드색 (아래 §6). 정보 가독성 우선, 순백에 가깝게 |

1장은 본문 페이지보다 **상하 여백을 약간 더 주어** 한 화면의 완성도·균형감을 확보한다.

## 2. 유형 ① 포스터형 (Poster)

### 추천 용도
모집 공고 · 신청 안내 · 간단한 정책 공지 · 행사 안내 · 참여 독려 · 공모전 모집

### 대표 사례
청년자문단 모집 · 국민자문단 모집 · 요소수 매점매석 금지 · 폐자원 수입관세 안내 · 설명회 개최 안내

### 페이지 구조
```
┌─────────────────────────────────────┐
│ ① 시리즈 칩 + 기관 로고(우)          │  ← 상단 8%
├─────────────────────────────────────┤
│ ② 강한 헤드라인 (1~2줄, 정책명 강조) │  ← 18~24%
├─────────────────────────────────────┤
│ ③ 대표 3D 일러스트 / 상징 오브젝트   │  ← 30~38%
├─────────────────────────────────────┤
│ ④ 핵심 안내 (대상·기간·방법)         │  ← 20~26%
│    [컬러 칩 헤더] + 불릿 2~4개        │
├─────────────────────────────────────┤
│ ⑤ CTA 밴드 (신청 방법·문의처)        │  ← 10~12%
├─────────────────────────────────────┤
│ ⑥ 발행 기관 시그니처                 │  ← 4%
└─────────────────────────────────────┘
```

### 디자인 특징
- 강한 헤드라인 중심, 공공기관 포스터 톤
- 신청기간·대상·문의처를 **명확한 위계**로 분리
- 하단에 **CTA(Call To Action)** 밴드 1개 — 색 대비로 시선 유도
- 핵심 정보만 간결하게, 장식 최소화

### 썸네일 컨셉
"정부 공고문 스타일의 깔끔하고 신뢰감 있는 포스터"

## 3. 유형 ② 1장 요약형 (Infographic Summary)

### 추천 용도
정책 성과 발표 · 경제지표 소개 · 통계자료 설명 · 예산 현황 · 제도 개편 요약

### 대표 사례
국가신용등급 A 유지 · 국내총생산(GDP) 현황 · 소비자물가 동향 · 수출입 통계 · 세수 현황

### 페이지 구조
```
┌─────────────────────────────────────┐
│ ① 시리즈 칩 + 기관 로고(우)          │  ← 상단 8%
├─────────────────────────────────────┤
│ ② 핵심 제목 (지표명·기간)            │  ← 12~16%
├─────────────────────────────────────┤
│ ③ 대표 수치 블록 (대형 숫자 1~3개)   │  ← 26~32%
│    [숫자 + 단위 + 증감 화살표]        │
├─────────────────────────────────────┤
│ ④ 그래프·아이콘 시각화               │  ← 24~30%
│    (막대/꺾은선/도넛 + 비교)          │
├─────────────────────────────────────┤
│ ⑤ 정책 의미 · 기대효과 (1~2줄)       │  ← 10~14%
├─────────────────────────────────────┤
│ ⑥ 발행 기관 시그니처 + 출처 각주     │  ← 4~6%
└─────────────────────────────────────┘
```

### 디자인 특징
- **숫자 중심 시각화** — 대표 수치를 가장 크게
- 인포그래픽 구성, 데이터 이해도 우선
- 증감(▲▼)·비교(現→改)·배수(×2) 표현 적극 활용
- 출처·기준시점은 흐린 그레이 메타로 분리

### 썸네일 컨셉
"경제 데이터를 한눈에 보여주는 인포그래픽 스타일"

## 4. 유형 ③ 텍스트 강조형 (Typography Focus)

### 추천 용도
신규 정책 홍보 · 정책 메시지 전달 · 캠페인 홍보 · 정책 브랜드화 · 정부 비전 홍보

### 대표 사례
새로운 경제정책 발표 · 민생안정 정책 · 규제혁신 추진 · 미래성장전략 · 경제활력 대책

### 페이지 구조
```
┌─────────────────────────────────────┐
│ ① 시리즈 칩 (소)                     │  ← 상단 6%
├─────────────────────────────────────┤
│                                     │
│ ② 초대형 핵심 메시지                 │  ← 46~56%
│    (2~4줄, 키워드 컬러 강조)          │
│                                     │
├─────────────────────────────────────┤
│ ③ 짧은 보조 설명문 (1~2줄)           │  ← 14~18%
├─────────────────────────────────────┤
│ ④ 정책명 + 기관 로고                 │  ← 하단 10~14%
└─────────────────────────────────────┘
```

### 디자인 특징
- **대형 타이포그래피** 중심, 이미지보다 메시지 우선
- 강렬한 컬러 액센트 (배경/밑줄/블록 중 1종 통일)
- 일러스트는 보조 또는 생략, SNS 공유 최적화
- 여백을 넉넉히 — 메시지가 호흡하도록

### 썸네일 컨셉
"강렬한 타이포그래피와 컬러 중심의 정책 홍보 디자인"

2. **굵기 + 액센트 컬러**: `**모두의 '로컬창업'**`
3. **밑줄 액센트**: 글자 아래 4–6 px 라인

## 7. 일러스트레이션 가이드

표지·본문과 같은 **3D 매트 렌더 룩** 유지. 사진/플랫 아이콘 혼용 금지.

### 포스터형
- 대표 캐릭터 + 1~2개 상징 오브젝트(서류·달력·확성기 등)
- 캔버스 폭의 **40~55%**, 중앙 또는 헤드라인 아래 배치
- 배경 없이 누끼, 그림자만 살짝

### 1장 요약형
- 일러스트보다 **그래프·아이콘 시각화**가 주역
- 막대/꺾은선/도넛 그래프는 무드 액센트 컬러로 단순하게
- 보조 아이콘은 120 × 120 ~ 200 × 200 px

### 텍스트 강조형
- 일러스트 최소화 또는 생략 (타이포가 주역)
- 사용 시 메시지 뒤 은은한 배경 그래픽 수준으로

### 화살표·흐름 표현
```
■ 메인 항목 (큰 사각형, 굵게)        ■ 컬러: #1A2238
➡ 하위 보조 항목 (작은 화살표, 인덴트)  ➡ 컬러: 액센트, 들여쓰기 24~32 px
```

## 8. 보조 그래픽 요소

### 시리즈 칩 (상단 좌측)
- 라운드 12 px, 좌우 패딩 20 px, 높이 44~50 px
- 우측에 기관 로고 인라인 배치 가능

### 안내 카드 / 수치 블록 컨테이너
- 라운드 24~32 px, 그림자 `0 4 16 rgba(0,0,0,0.04)`
- 내부 패딩 32~40 px

### CTA 밴드 (포스터형 전용)
- 페이지 하단 가로 전폭 또는 라운드 사각형
- 액센트 풀컬러 + 흰 텍스트, "지금 신청하기 →" 식

### 강조 배지 (`×2`, `최대 5%P`, `우대`)
- 작은 라운드 사각형/리본, 옐로우·코랄·민트
- 본문과 다른 액센트로 시선 끌기

## 9. 체크리스트 (1장 출고 전)

- [ ] 한 장에 핵심 메시지가 **1개**로 좁혀졌는가
- [ ] 보도자료 성격에 맞는 유형(①/②/③)을 골랐는가
- [ ] 헤드라인(또는 대표 수치/핵심 메시지)이 모바일 썸네일에서 즉시 읽히는가
- [ ] 키워드 강조 방식이 한 장 내 **1종으로 통일**되었는가
- [ ] (포스터형) 대상·기간·방법·문의처가 위계로 분리되고 CTA가 있는가
- [ ] (요약형) 대표 수치가 가장 크고, 출처·기준시점이 메타로 분리되었는가
- [ ] (강조형) 여백이 충분하고 보조 설명이 1~2줄로 짧은가
- [ ] 메타 정보(`(’26.~, 1억원)`)가 본문보다 흐린 그레이인가
- [ ] 3D 일러스트 룩이 표지·본문 시스템과 동일한가
- [ ] 하단 기관 시그니처(로고) 위치·크기·컬러가 일관된가
- [ ] 일본·북한·식민지 잔재, 정치 이념·갈등, 혐오 표현이 없는가
