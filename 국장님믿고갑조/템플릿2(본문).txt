# 재정경제부 카드뉴스 본문 페이지 디자인 템플릿

본 문서는 재정경제부 카드뉴스 본문 페이지를 자동 생성하기 위한 디자인 가이드이다. 표지는 별도 `design_front_page.md`를 따르고, 본문은 정책 내용을 국민이 빠르게 이해할 수 있도록 **큰 제목, 짧은 문장, 3D 일러스트, 굵은 키워드, 여백 중심 레이아웃**을 기본 원칙으로 한다.

- 정부로고(기관로고, 재정경제부 로고)는 C:\Users\USER\AI-Education\logo.png에 위치해있으니 해당 로고를 사용해.
---

## 1. 기본 캔버스 규격

### 1-1. 전체 비율

- 기본 크기: **800 x 1000px**
- 비율: **4:5 세로형 카드뉴스**
- SNS 업로드 대응: 인스타그램 피드형, 페이스북 카드형에 적합
- 안전 여백: 좌우 최소 **55~70px**, 상하 최소 **40~60px**
- 본문 영역은 상단 헤더, 중앙 콘텐츠, 하단 로고 영역으로 구분한다.

### 1-2. 전체 구조

```text
┌──────────────────────────────┐
│ ① 상단 헤더/시리즈 라벨       │  약 60~110px
├──────────────────────────────┤
│ ② 대제목 영역                 │  약 100~160px
├──────────────────────────────┤
│ ③ 본문 콘텐츠 영역            │  약 650~760px
│   - 텍스트 블록               │
│   - 3D 일러스트               │
│   - 인포그래픽                │
│   - 말풍선/라벨               │
├──────────────────────────────┤
│ ④ 하단 기관 로고              │  약 60~90px
└──────────────────────────────┘
```

### 1-3. 본문 페이지 유형

본문은 크게 4가지 유형으로 나눈다.

1. **종합 요약형**: 한 페이지에 3~4개 정책 과제를 나열
2. **섹션 설명형**: 하나의 정책 축을 제목으로 두고 2~3개 세부과제 설명
3. **인포그래픽형**: 제도 구조, 지원 흐름, 지역 확산 구조 등을 시각화
4. **마무리 선언형**: 마지막 장에서 정책 방향과 정부 의지를 요약

## 3. 폰트 스타일

### 3-1. 권장 폰트

한국어 정책 카드뉴스 특성상 다음 계열을 우선한다.

- Pretendard
- Noto Sans KR
- Gmarket Sans
- Spoqa Han Sans Neo
- Apple SD Gothic Neo

### 3-2. 글자 굵기

- 대제목: **ExtraBold / Bold**
- 중제목·라벨: **Bold**
- 본문: **Medium / SemiBold**
- 보조 설명: **Regular / Medium**

### 3-3. 권장 크기

800 x 1000px 기준:

| 요소 | 권장 크기 | 굵기 | 설명 |
|---|---:|---|---|
| 상단 시리즈 라벨 | 22~28px | Bold | 흰색 캡슐 안에 배치 |
| 상단 보조 문구 | 20~26px | Medium/Bold | 시리즈 설명, 슬로건 |
| 대제목 | 46~62px | ExtraBold | 한 페이지 핵심 메시지 |
| 섹션 라벨 | 26~34px | Bold | 구름형/캡슐형 라벨 |
| 본문 핵심 문장 | 30~40px | Medium/Bold | 1~2줄 단위 |
| 강조 키워드 | 32~42px | ExtraBold | 수치, 정책명, 효과 |
| 보조 설명 | 20~26px | Regular/Medium | 일정, 조건, 괄호 설명 |
| 하단 로고 텍스트 | 18~22px | Regular | 중앙 정렬 |

### 3-4. 강조 방식

- 문장 전체보다 **핵심 키워드만 굵게** 처리한다.
- 숫자, 비율, 일정, 정책명은 반드시 굵게 처리한다.
- 예시:

```text
농축수산물 최대 50% 할인
불공정행위 등 집중 점검
지역 내 대중교통 이용금액 추가
AI 도우미 서비스 신설
```

## 4. 상단 헤더 디자인

본문 페이지는 상단에 시리즈명 또는 섹션 라벨을 둔다.

### 4-1. 녹색 소비·관광형 헤더

```text
┌─────────────────────────────┐
│ [하얀 캡슐 라벨]             │
│ 하면 Save, 쓰면 Wave         │
│ 녹색 소비, 혜택의 물결       │
└─────────────────────────────┘
```

- 위치: 좌상단, x=55~65px, y=30~45px
- 형태: 흰색 둥근 캡슐 또는 구름형 말풍선
- 크기: 약 300~470px 너비, 55~75px 높이
- 텍스트: 2줄 구성 가능
- 첫 줄에 영어 단어를 섞어 리듬감을 준다.
  - 예: `Save`, `Wave`, `Smile`, `Style`, `Go`, `Grow`, `Benefit`, `Merit`
- 두 번째 줄은 정책 의미를 설명한다.

### 4-2. 지역상권형 헤더

```text
[2026 모두의 지역상권 추진전략] 點: 창의 | 활력 상권의 씨앗, 로컬창업의 활성화
```

- 위치: 최상단 좌우로 길게 배치
- 배경: 페이지 상단 전체에 블루/퍼플/오렌지 띠를 깔 수 있음
- 좌측: 흰색 캡슐 안에 프로젝트명
- 우측: 섹션 한자 키워드 + 설명
  - `點: 창의`
  - `線: 성장·집적`
  - `面: 확산`
- 얇은 곡선 라인 패턴을 배경에 넣어 정책 확산 느낌을 준다.

### 4-3. 기관 로고

- 상단 우측 또는 하단 중앙에 배치
- 본문 페이지에서는 주로 우상단 또는 하단 중앙 사용
- 로고가 상단에 있을 경우, 제목과 겹치지 않도록 여백 확보
- 하단 중앙 로고는 마지막 정리감 부여용으로 적합

## 5. 대제목 디자인

### 5-1. 대제목 위치

- 상단 헤더 아래, x=55~70px, y=115~170px
- 폭: 680~700px
- 줄 수: 1~2줄 권장
- 너무 긴 경우 2줄로 나누고 행간을 좁게 한다.

### 5-2. 대제목 색상

- 친환경·소비: 진한 녹색
- 지역상권: 흰색 대제목 또는 섹션 컬러 대제목
- 기업성장: 흰색 또는 보라색
- 관광확산: 흰색 또는 주황색

### 5-3. 대제목 스타일 예시

```text
친환경 녹색 소비 촉진
소비분위기 조성 중동전쟁 부담 완화
친환경 관광 붐 조성
방한 관광객 유치 확대
생계안정 지원 소비여력 보완

아이디어만으로 충분한 모두의 ‘로컬창업’
지역 문제 해결형 로컬창업 촉진
민간 주도의 로컬기업 성장 촉진
K-컬처를 즐기는 대표 관광상권 조성
상권의 지속성장을 위한 제도 강화
```

### 5-4. 제목 작성 원칙

- 명사형으로 끝내 정책자료 느낌을 유지한다.
- 한 페이지당 하나의 핵심 메시지만 제목화한다.
- 가능하면 **정책대상 + 정책효과** 구조로 작성한다.
- 예: `대중교통 연계 친환경 관광 활성화`

## 6. 본문 레이아웃 패턴

## 패턴 A. 4분할 정책 요약형

여러 정책을 한 페이지에 요약할 때 사용한다.

### 구조

```text
[상단 헤더] [기관 로고]

[대제목]

┌─────────────┐      ┌─────────────┐
│ 일러스트     │      │ 텍스트       │
│ + 라벨       │      │ 2~3줄        │
└─────────────┘      └─────────────┘

┌─────────────┐      ┌─────────────┐
│ 일러스트     │      │ 텍스트       │
│ + 라벨       │      │ 2~3줄        │
└─────────────┘      └─────────────┘

[하단 로고]
```

### 사용 장면

- 친환경 소비 정책 3~4개 요약
- 생계안정 지원 과제 요약
- 관광 활성화 과제 나열

### 디자인 특징

- 각 정책 항목은 텍스트와 일러스트를 교차 배치한다.
- 텍스트는 2~3줄 이내로 구성한다.
- 일러스트는 실제 사진보다 3D 오브젝트를 우선한다.
- 페이지 전체에 선이나 박스를 과도하게 쓰지 않고 여백으로 구분한다.

### 권장 구성

- 항목 수: 3~4개
- 이미지 수: 3~4개
- 한 항목당 텍스트: 20~35자 내외
- 강조 키워드: 항목당 1~2개

## 패턴 B. 큰 흰색 카드형 설명 페이지

지역상권 전략 본문처럼 하나의 큰 카드 안에 정책 내용을 정리할 때 사용한다.

### 구조

```text
[상단 컬러 배경]
[시리즈 라벨 + 섹션 설명]
[대제목]

┌──────────────────────────────┐
│ [섹션 라벨]                   │
│ · 주요 문장                   │
│   → 보조 설명                 │
│                 [3D 이미지]   │
│                              │
│ [섹션 라벨]                   │
│ · 주요 문장                   │
│   → 보조 설명                 │
│ [3D 이미지]                   │
└──────────────────────────────┘

[하단 로고]
```

### 카드 규격

- 위치: x=45~60px, y=170~210px
- 크기: 너비 680~710px, 높이 700~760px
- 배경: 흰색 `#FFFFFF`
- 모서리: 20~32px 둥근 모서리
- 그림자: 매우 약하게 적용하거나 생략

### 특징

- 페이지 상단 배경은 섹션 컬러로 채우고, 본문은 흰색 카드 위에 배치한다.
- 내용이 많아도 카드 내부에서 질서 있게 정렬된다.
- 정책 설명, 예산, 일정, 지원대상 등 복잡한 정보를 정리하기 좋다.

### 세부 텍스트 규칙

- 주요 문장은 `·` 불릿 사용
- 하위 설명은 `→` 화살표 사용
- 예산·일정은 괄호 처리
- 핵심 단어는 굵게
- 한 섹션은 3~5줄 이내

## 패턴 C. 라벨 + 인포그래픽 혼합형

제도 구조, 단계별 정책, 지원 흐름을 설명할 때 사용한다.

### 구조

```text
[대제목]

[라벨 1]
· 핵심 설명
→ 세부 설명
          [구조형 3D 인포그래픽]

[라벨 2]
· 핵심 설명
→ 세부 설명
          [비교/흐름도 이미지]
```

### 사용 장면

- 로컬기업 성장 지원 구조
- 관광상권 조성 구조
- 상생협약, 기금, 펀드, 금융지원 흐름
- 소비쿠폰, 교통비 환급, 할인 구조

### 이미지 스타일

- 미니어처 도시, 상점, 시장, 버스, 여행가방, AI 로봇 등 3D 오브젝트 사용
- 흐름은 화살표, 점선, 연결선으로 표현
- 지도, 건물, 돈, 쿠폰, 스마트폰 등 정책 수단을 상징하는 오브젝트 배치

## 패턴 D. 하단 아이콘 단계형

정책 이용 흐름이나 관광 패키지 구성을 보여줄 때 사용한다.

### 구조

```text
[본문 핵심 문장]

[아이콘 박스] → [아이콘 박스] → [아이콘 박스] → [아이콘 박스]
  입국 방문       숙박             체험             식음
```

### 박스 스타일

- 모서리 둥근 사각형
- 테두리: 그린/블루/오렌지 2~3px
- 아이콘은 중앙 상단, 라벨은 하단 중앙
- 박스 간 연결 화살표 사용 가능

### 적합한 사용 장면

- 지원 절차
- 정책 이용 단계
- 여행 패키지 구성
- 카드뉴스 마지막 전 요약 페이지

---

## 패턴 E. 마무리 선언형 페이지

카드뉴스 마지막 장에 사용한다.

### 구조

```text

        [3D 인물/캐릭터]

정부는
핵심 정책수단을 통해
정책목표를 추진하고,
국민 체감 성과를 만들어가겠습니다.

        [기관 로고]
```

### 디자인 원칙

- 배경은 흰색 또는 아주 연한 회색
- 이미지와 문구를 중앙 정렬한다.
- 텍스트는 4~6줄 내외
- 핵심 키워드는 굵게 처리한다.
- 본문 페이지 중 가장 여백이 많아야 한다.

### 텍스트 예시

```text
정부는 민·관이 함께
모든 정책역량을 총동원하여

민생안정 지원 과제를
신속하고 체계적으로 추진해 나가겠습니다.
```

```text
정부는
재정지원과 제도개선을 통해
지역상권 혁신 기반을 구축하고,

만들어 가겠습니다.
```

## 7. 섹션 라벨 디자인

### 7-1. 구름형 라벨

본문에서 가장 자주 쓰이는 라벨이다.

```text
[ 로컬기업 발굴·지원 ]
[ AI 3종 서비스 ]
[ 성장자금 ]
[ 기술혁신 제조 ]
[ 로컬 관광상권 ]
```

### 디자인

- 배경색: 해당 섹션 컬러
- 글자색: 흰색
- 모양: 구름형 또는 캡슐형
- 모서리: 20~30px
- 내부 여백: 좌우 24~32px, 상하 10~14px
- 글자 크기: 26~32px
- 굵기: Bold

### 7-2. 라벨 배치

- 각 정책 설명 블록의 시작점에 배치
- 텍스트 본문보다 약간 위에 둔다.
- 같은 페이지 내 라벨 색은 통일한다.
- 서로 다른 정책축은 색상으로 구분한다.

## 8. 본문 텍스트 작성 규칙

### 8-1. 문장 길이

- 한 줄 15~22자 내외
- 한 항목 2~4줄
- 한 페이지 총 텍스트는 많아도 12~16줄 이하 권장

### 8-2. 본문 문체

- 간결한 정책 설명체 사용
- 조사와 수식어를 줄이고 핵심 명사 중심으로 작성
- `추진`, `확대`, `지원`, `마련`, `운영`, `개발`, `강화` 등 정책 동사 사용

### 8-3. 불릿 체계

```text
· 주요 정책 설명
  → 세부 추진 내용
  → 기대 효과 또는 지원 방식
```

- 1차 불릿: `·`
- 2차 설명: `→`
- 보조 일정: 괄호 `()`
- 예산/수치: 굵게

### 8-4. 강조 처리

강조 대상:

- 정책명
- 숫자/비율/금액
- 대상
- 일정
- 효과

예시:

```text
매년 로컬창업가 1만명 발굴,
로컬기업 1천개사 육성

지방 로컬창업 지원 비중 90%까지 확대

농축수산물 최대 50% 할인

상가 관리비 내역 제공 의무화
```

## 9. 이미지 스타일 가이드

### 9-1. 기본 이미지 톤

- 3D 미니어처 일러스트 중심
- 부드러운 점토/클레이 느낌
- 둥근 형태, 낮은 대비, 밝은 조명
- 배경이 투명하거나 흰색에 자연스럽게 놓이는 오브젝트
- 실사 이미지는 보조적으로만 사용

### 9-2. 주요 오브젝트 유형

정책 분야별 추천 오브젝트:

| 분야 | 이미지 요소 |
|---|---|
| 소비·할인 | 쿠폰, 카드, 장바구니, 지갑, 상품권, 영수증 |
| 친환경 | 나뭇잎, 텀블러, 전기차, 충전기, 태양광, 풍력 |
| 관광 | 여행가방, 비행기, 지도 핀, 버스, 숙박시설, 관광객 |
| 지역상권 | 상점, 시장, 골목, 간판, 로컬브랜드 매장, 전통가옥 |
| 창업·AI | AI 로봇, 노트북, 데이터 아이콘, 스마트폰, 검색창 |
| 금융·지원 | 돈, 동전, 지폐, 금고, 펀드 흐름도, 지원기관 건물 |
| 제도·협약 | 문서, 계약서, 도장, 악수, 체크 표시, 안내판 |
| 생계안정 | 우산, 가족, 취약계층, 수도꼭지, 연료통, 에너지 고지서 |

### 9-3. 인물 스타일

- 3D 캐릭터형 인물 사용
- 표정은 밝고 긍정적
- 과도하게 사실적인 얼굴 지양
- 남녀·연령·직업 다양성 반영
- 정책 대상이 명확한 경우 인물 속성 반영
  - 청년 창업가
  - 소상공인
  - 관광객
  - 고령층
  - 공무원
  - 가족

### 9-4. 실사 이미지 사용

실사 사진은 제한적으로 사용한다.

- 정책 대상의 현실감을 줄 때만 사용
- 배경과 자연스럽게 합성
- 인물 실사는 하단 또는 좌측에 배치해 보조 이미지로 사용
- 3D 오브젝트와 섞을 경우 그림자와 색감을 맞춘다.

### 9-5. 이미지 배치

- 텍스트와 이미지가 같은 시각적 무게를 갖도록 배치한다.
- 이미지가 텍스트를 가리지 않도록 최소 25px 이상 간격 확보
- 큰 3D 이미지는 우측 또는 중앙 하단에 배치
- 작은 오브젝트는 라벨 옆 또는 문장 중간 보조 요소로 배치

## 10. 페이지별 상세 템플릿

## 10-1. 녹색 소비 종합 페이지

### 용도

정책 과제를 4개 내외로 요약한다.

### 레이아웃

```text
상단: 캠페인 슬로건 캡슐 + 기관 로고
중앙 상단: 진한 녹색 대제목
본문: 4개 정책 과제를 이미지+텍스트로 배치
하단: 기관 로고 또는 여백
```

### 텍스트 예시

```text
친환경 녹색 소비 촉진

기후주간 모두의 녹색소비 캠페인
녹색소비주간 릴레이 개최

에너지 저소비 제품 판매 매장
지역사랑상품권 추가 할인

공공·민간부문 차량 전환 확대
전기차 전환 가속화 방안 마련

유연근무 확대,
대중교통 활성화
```

### 이미지 예시

- 텀블러, 녹색 포인트, 에너지 절감 제품
- 전기차, 충전기
- 지역사랑상품권, 지갑, 버스
- 친환경 매장 3D 미니어처

---

## 10-2. 할인·부담 완화 페이지

### 용도

농축수산물 할인, 가격 점검, 소비쿠폰 등 생활비 부담 완화 정책 설명

### 레이아웃

```text
대제목: 상단 좌측, 진한 녹색
좌상단: 장바구니/쿠폰 대형 이미지
우측: 핵심 할인 문장
중하단: 농축산물/수산물 박스 2개
```

### 구성 요소

- 상단 대형 이미지: 장바구니 + 할인 쿠폰
- 중간 핵심 문장: 2~4줄
- 하단 박스: 초록 테두리 박스 2개
- 각 박스에 소분류 라벨 부착

### 하단 박스 스타일

```text
┌──────────────────────┐
│ [농축산물]             │
│ 이미지1   이미지2   이미지3│
│ 설명     설명     설명    │
└──────────────────────┘
```

- 테두리: 연두색 2px
- 라벨: 좌상단에 진한 녹색 캡슐
- 내부 이미지는 균등 간격 배치

## 10-3. 관광 붐 조성 페이지

### 용도

숙박쿠폰, 관광 페스타, 연가보상비, 여행 활성화 등을 설명

### 레이아웃

```text
상단: 슬로건 캡슐 + 기관 로고
대제목: 좌측 2줄
우상단: 친환경 관광 3D 오브젝트
중앙: 주요 정책 이미지
하단: 실사/인물 + 보조 정책 문장
```

### 이미지 요소

- 숙박시설 3D 미니어처
- 복주머니/할인 쿠폰
- 여행객, 캐리어, 텀블러
- 버스, 지도, 관광지

### 특징

- 이미지가 페이지 분위기를 많이 좌우한다.
- 여행·관광 이미지는 밝은 녹색, 하늘색, 모래색을 섞는다.
- 정책효과를 딱딱하게 쓰기보다 행동 중심 문구로 구성한다.

## 10-4. 지역상권 큰 카드 페이지

### 용도

정책축별 세부 대책을 정리하는 기본 본문 템플릿

### 레이아웃

```text
상단 컬러 영역
- 좌측 프로젝트명 캡슐
- 우측 섹션 설명
- 대제목

본문 흰색 카드
- 라벨 2~3개
- 각 라벨별 정책 설명
- 3D 인포그래픽 삽입

하단 중앙 로고
```

### 카드 내부 규칙

- 본문은 라벨 아래 15~25px 간격
- 이미지는 오른쪽 또는 문단 사이 배치
- 세부 정책이 많으면 두 개의 큰 블록으로 나눈다.

### 예시 구조

```text
[로컬기업 발굴·지원]

· 권역별 로컬창업 멘토단 구성·운영

· 자연어 검색으로 상권분석, 지원사업 정보,

→ 상권 데이터 기반 AI 내비게이션 제공
→ 업종 특성별 AI 교육과정 구축
```

## 13. 자동 생성 시 품질 체크리스트

### 13-1. 레이아웃 체크

- [ ] 800 x 1000px, 4:5 비율 유지
- [ ] 좌우 안전 여백 55px 이상 확보
- [ ] 상단 헤더와 대제목이 겹치지 않음
- [ ] 본문 텍스트와 이미지 간격 25px 이상 확보
- [ ] 하단 로고가 잘리지 않음

### 13-2. 텍스트 체크

- [ ] 대제목은 1~2줄 이내
- [ ] 한 페이지 핵심 메시지는 1개
- [ ] 본문 문장은 2~4줄 단위로 분리
- [ ] 숫자, 대상, 정책명은 굵게 처리
- [ ] 어려운 정책용어는 쉬운 표현으로 보완

### 13-3. 이미지 체크

- [ ] 이미지에 불필요한 텍스트가 들어가지 않음
- [ ] 3D 일러스트 톤이 통일됨
- [ ] 정책대상과 이미지가 일치함
- [ ] 특정 브랜드나 민간기업 로고가 없음
- [ ] 실사와 3D 이미지 혼합 시 색감이 어색하지 않음

### 13-4. 정부 콘텐츠 적합성 체크

- [ ] 과장 표현 없음
- [ ] 정치적 오해 소지가 있는 표현 없음
- [ ] 정책 대상·시기·금액이 정확함
- [ ] 기관명과 로고 위치가 일관됨
- [ ] 최종 승인 전 담당자 검토 단계 필요

## 14. Cursor/AI 디자인 생성 프롬프트 예시

```text
아래 정책자료를 바탕으로 재정경제부 카드뉴스 본문 페이지를 만들어줘.

디자인 기준:
- 800x1000px 세로형 4:5 카드뉴스
- 밝은 오프화이트 배경
- 상단에는 시리즈 라벨과 기관 로고 배치
- 대제목은 굵고 크게, 1~2줄
- 본문은 3D 미니어처 일러스트와 짧은 정책 문장 중심
- 핵심 수치와 정책명은 굵게 강조
- 라벨은 구름형 또는 둥근 캡슐형
- 전체 톤은 정부기관 카드뉴스처럼 깔끔하고 신뢰감 있게
- 이미지 스타일은 부드러운 3D 클레이 일러스트
- 하단 중앙에는 기관 로고 배치

생성할 페이지 유형:
1. 종합 요약형
2. 큰 흰색 카드형 설명 페이지
3. 라벨+인포그래픽 혼합형
4. 마무리 선언형

출력:
- 카드뉴스 페이지별 제목
- 카드별 본문 문안
- 이미지 생성 프롬프트
- 레이아웃 설명
- 색상 팔레트
```

## 15. 권장 페이지 구성 순서

일반적인 정책 카드뉴스는 다음 흐름을 따른다.

```text
1p. 표지
2p. 전체 추진방향 요약
3p. 정책축 1 설명
4p. 정책축 2 설명
5p. 정책축 3 설명
6p. 정책축 4 설명
7p. 제도개선 또는 후속조치
8p. 마무리 선언
```

본문 페이지는 독립적으로 읽혀야 하므로, 각 페이지마다 `대제목 + 핵심 이미지 + 핵심 문장`이 반드시 포함되어야 한다.

## 16. 핵심 디자인 원칙 요약

1. **큰 제목**: 한 페이지의 정책 메시지를 1~2줄로 압축한다.
2. **짧은 문장**: 설명은 길게 쓰지 않고 핵심 문장 중심으로 나눈다.
3. **굵은 키워드**: 정책명, 숫자, 효과는 반드시 강조한다.
4. **3D 일러스트**: 정책을 친근하고 직관적으로 보이게 한다.
5. **넓은 여백**: 복잡한 정책도 답답해 보이지 않게 만든다.
6. **섹션 컬러**: 녹색·파랑·보라·주황으로 정책축을 구분한다.
7. **검수 가능성**: AI가 만든 문안은 담당자가 수정·승인할 수 있어야 한다.
